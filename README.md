# Saranath College Website

School Website's New Features

## Pages

- `index.html` - Dev Home
- `pages/student-life.html` - Academic pathways, activities, gallery and community feedback
- `pages/clubs.html` - Club directory and category filters
- `pages/news-events.html` - School news and event listings
- `pages/news-story.html` - Each news story view
- `pages/student-services.html` - Student services
- `pages/feedback-report.html` - Community ideas for review

## Content and assets

Page content that changes frequently is kept in the JavaScript data files:

- `js/student-life.js` - Academic streams and student-life gallery
- `js/clubs.js` - Club listings
- `js/school-content.js` - Shared school news and event data
- `js/news-events.js` - News and event page rendering
- `js/student-services.js` - Student services and feedback-report data

Images and Fonts in `assets/images/` and `assets/fonts/`.

The Feedback Report with anonymous ideas, concerns and community feedback.
